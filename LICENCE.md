## 🧩 About

**Hell Let Loose Vietnam Companion** is a curated list of Hell Let Loose Vietnam open-source tools:

- **Overlays** — on-screen helpers, layout notes, squad info viewer, spawnpoint switcher
- **Quality-of-Life Helpers** — loadout catalog, kit manager, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Practice Helpers
- Spawnpoint Switcher — practice from any rally point
- Show Hitboxes — visualize cover and line-of-sight zones
- Replay Notes — record and review match runs
- Playback Speed — adjust replay playback for study (0.1x to 5x)

### 🎨 Catalog & Loadouts
- Loadout Catalog — browse kits, camos, and gear presets
- Custom Skin Notes — organize player cosmetics
- Squad Marker Trail — improved squad visibility

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any map layout
- Stance Control — manually switch stance mid-run
- Movement Buffer Notes — chain complex maneuvers in the editor
